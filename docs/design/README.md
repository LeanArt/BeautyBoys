# Design research & spec (archive)

How the **Ley Line Atlas** design system came about. The maintained reference is [`../DESIGN.md`](../DESIGN.md) and the
live style guide at `/design-system/`; these files are the working record behind it.

| File | What |
|---|---|
| `BRIEF.md` | The design brief every step worked from |
| `research-wowhead-blizzard.md` | Visual language and UX patterns of Wowhead (Forever) and Blizzard's official Forever pages – what to reuse, what not to imitate |
| `research-guide-wikis.md` | UX patterns of game guide sites and wikis (Warcraft Tavern, Maxroll, OSRS Wiki, warcraft.wiki.gg, …) |
| `research-audit.md` | Audit of the previous design against Anthropic's frontend-design and UI/UX Pro Max guidance |
| `direction-A.md` | Direction A, "Ley Line Atlas" (identity & immersion first) – the winner |
| `direction-B.md` | Direction B, "Lantern Trail" (usability & second-screen first) – runner-up, several ideas grafted |
| `FINAL-SPEC.md` | The judged, merged, implementable spec |

Screenshot and script paths inside these files point to a temporary workspace and are not part of the repo.
